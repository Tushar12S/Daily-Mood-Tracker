# 🌤️ Daily Mood Tracker

A visually appealing, interactive, and fully responsive web project that allows users to select and track their daily mood using emoji buttons. The background color dynamically changes to reflect the selected emotion, providing an engaging and intuitive user experience — all built with **HTML and CSS only**.

## 💡 Features

- 🎭 **Mood Selection**: Choose between moods like Happy, Sad, Excited, and Calm.
- 🎨 **Dynamic Background**: Background color smoothly changes based on selected mood.
- 🖌️ **Styled Mood Icons**: Emoji icons styled with modern hover and active states.
- 📱 **Responsive Design**: Works seamlessly across desktop, tablet, and mobile devices.
- ✨ **Clean UI**: Utilizes Flexbox, transitions, and Google Fonts for aesthetic layout.
